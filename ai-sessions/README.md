# Native dialogue provenance

The JSONL files collected here are unchanged snapshots from the native Codex session store, explicitly selected for this continuation and its three agents. The working directory of this chat differs from the original repository, so session IDs are selected explicitly rather than broadening automatic discovery to unrelated chats.

The original implementation conversation before the Codex handoff is **missing**. The user confirmed that they do not have its export. No original dialogue has been reconstructed, and documentation/handoff notes are not dialogue exports. Therefore the archive cannot claim a complete export of every conversation used during the assignment.

The manifest records capture time, session IDs, original filenames, byte lengths and SHA-256 hashes. Active sessions can append after capture; a snapshot contains only the native bytes present at the stated time.
